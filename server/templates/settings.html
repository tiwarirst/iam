Edge Node Daemon Deployment Matrix

Target machines require the lightweight universal agent to execute native OS account commands. Execute the respective bootstrap commands on your target nodes:

Linux POSIX Ubuntu / Debian / RHEL 
pip install -r agent/requirements.txt
sudo python agent/universal_agent.py
Windows NT Windows 10/11 / Server 
pip install -r agent/requirements.txt
python agent\universal_agent.py
Cryptographic Key Parity Required: Both the control plane and edge daemons must share the identical NIYANTA_SECRET_KEY. Mismatched secrets result in instantaneous 401 Unauthorized handshake rejections.
